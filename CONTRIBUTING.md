# Contributing

Paddle is a personal browser. Walker merges what he wants and closes the rest.

## How

1. Fork. Do not ask for write access on this repo.
2. Branch from `main`.
3. Open a pull request against `main`.
4. Wait. A closed PR is a no.

Use GitHub's noreply commit email. Do not put secrets, credentials, notary profiles, or personal data in the tree, commit metadata, or screenshots.

Do not add GitHub Actions workflows unless the PR is specifically about CI.

`README.md`'s `config.json` table and shortcut action names are checked by tests. Keep them in sync with `PaddleConfig` and `MainMenu`.
